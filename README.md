# app-template
The Harper + React/Vite app every Immensus-generated web app starts from: one page, its frame and the build stamp. Sign-in and payments are kits under `kits/`, which the platform copies into an app only when its plan needs them.

Start with `CLAUDE.md` — the canonical brief for the builder and for every session. The harness (charters in `.claude/agents/`, commands in `.claude/commands/`, gates in `.github/workflows/`) is what every generated app inherits.
